## Sobre mí

Soy desarrollador Full Stack con experiencia en el desarrollo y mantenimiento de sistemas web administrativos para organismos públicos.

Trabajo principalmente con **React.js, Node.js, Express.js, JavaScript, APIs REST y bases de datos SQL/MySQL**. También cuento con formación en **QA Automation**, pruebas funcionales y automatización de pruebas web/mobile.

Me interesa construir soluciones claras, mantenibles y útiles, combinando frontend, backend, base de datos e integración de servicios.
