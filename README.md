### 🚀 Featured Experience

#### 🏛️ Patrimonio Municipal
Administrative web system for managing and visualizing municipal heritage assets.  
**Main work:** forms, tables, filters, modals, image management, data editing, and frontend/backend integration.

#### 🧾 Catastro — Parametrización de Formularios
System focused on cadastral form management and dynamic form configuration.  
**Main work:** administrative interfaces, dynamic forms, validations, API consumption, and database integration.

#### 👥 Atención Ciudadana — Gestión de Usuarios
User and permissions management system for the citizen service platform.  
**Main work:** user administration, access control, roles/permissions, and backend service integration.

#### 🚦 Movilidad Urbana — Gestión de Usuarios
Internal system for managing users in the Urban Mobility area.  
**Main work:** administrative modules, user management interfaces, backend integration, and maintenance of existing features.
